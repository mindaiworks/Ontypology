## 摘要

世界模型（World Model）已成為通用人工智慧的核心議題：一個能夠在內部「想像」世界如何運作、並據以預測與決策的模型，才是智慧的底座。然而，以大型語言模型（LLM）為唯一支柱的世界模型存在三個結構性缺口——**身份不連續、結構不可見、規則不開放**——它把世界知識隱藏在參數的統計分布裡，無法持久指認同一個對象、無法檢驗部件之間的依存關係、也無法用可公開的規則判定新情境的歸屬。

本文以本形學（Ontypology）為理論基礎，提出「世界模型的大腦」**WorldMind**：一套 LLM＋Mind Model 雙引擎、五層結構的應用架構，並給出一套可操作、可檢驗的「準確方法」——**世界建模六步驟**（形偵測、形定義、結構化、框架化、形式化、驗證修正）。方法以「異同→分合→形」的認知鏈為起點，以屬性／屬性值描述物件性狀，以空間容器與 SOM 描述身份與結構，以框架保證方法可重複套用，再以形邏輯三層判斷（容器、SOM、抽象）完成形式化，最後以預測-驗證-修正迴圈與五維準確性評估收斂。

在理論層面，本文建立容器身份公理、結構分級定理、三層判斷充要條件定理與形替換不變性定理，把形邏輯的判斷流程提升為可證明的性質；在應用層面，以智慧家庭場景與對話式 AI 為案例，展示三層判斷如何聯合運作，並設計純 LLM、RAG、LLM＋Mind Model 三方法對照評估。結果顯示，疊加 Mind Model 的世界模型在語義完整、假設可見、步驟可檢、層次一致、邊界明確五個維度上全面優於既有路線。本文主張：**世界模型需要的不是更大的參數量，而是一個懂得「形」的大腦。**

**關鍵詞**：世界模型、大腦、本形學、形邏輯、Mind Model、雙引擎、形庫、五維準確性

# 第一章 緒論：世界模型為何需要一個大腦

## 1.1 世界模型的定義與期待

所謂世界模型，指的是系統在內部建立的一份「世界如何運作」的可推演結構：給定當前狀態與一個動作，它能預測下一個狀態；給定一個假設情境，它能推演「如果……那麼……」的後果；當預測與觀察不符時，它能定位錯誤並修正自己。這三件事——預測、反事實、修正——正是人類認知系統每時每刻在做的事情。發展心理學的研究指出，嬰兒在極早期就具備物體恆存、因果直覺等核心知識，說明「世界模型」並非後天習得的奢侈品，而是智慧的底層配置。

近年來，大型語言模型（LLM）以龐大的參數隱含了大量世界知識，能流暢地描述場景、推演情節，儼然被視為世界模型的現成底座。然而「能描述」與「能檢驗」是兩件事：一個模型可以在文字上把杯子的描寫得鉅細靡遺，卻在杯子換了內容物之後認不出那是同一個杯子；可以列出零件清單，卻說不出拿掉哪個零件會使整體崩解；可以類比地猜測新物件的歸屬，卻給不出一條可公開驗證的判準。語言的流暢，掩蓋了結構的缺席。

## 1.2 純 LLM 世界模型的三個缺口

把純 LLM 的世界建模方式攤開來檢視，可以歸納出三個結構性缺口。

1. **身份不連續**：LLM 以 token 序列處理世界，對象的身份隨著描述的延續而流動，缺少一個「不隨內容物改變」的身份錨點，於是跨輪追蹤同一個物件成為難題。
2. **結構不可見**：部件之間的依存關係隱沒在共現統計裡，無法回答「拿掉杯底會怎樣」這種結構性問題，也無法在預測出錯時定位到具體的結構位置。
3. **規則不開放**：新情境的歸屬判斷靠類比與語感，缺少一條寫得出來、檢驗得了、可以修訂的判準，於是模型在邊界案例上表現不穩定，且無法解釋為什麼。

這三個缺口並非工程細節上的瑕疵，而是語言模型作為世界模型的本體論缺陷：它缺的不是資料，而是「形」——一份能同時承載身份、結構與生成規則的描述格式。這正是本形學的切入點。

## 1.3 本形學：一套準確的方法

本形學（Ontypology）主張：形（Type）並非天生存在，而是大腦先偵測「異同」，再透過「分」與「合」的動作畫出邊界之後才產生的結果。有了形之後，描述一個具體物件需要四個面向——**屬性**（它是什麼樣子）、**容器**（它在哪裡、身份是否獨立）、**SOM**（它由什麼組成、部件如何依存）、**框架**（這套描述方法能否重複套用）。四個面向合起來，恰好構成一個可檢驗的世界描述。本文所說的「準確的方法」，就是把這套理論轉化為可操作的建模程序：先有異同、再畫邊界、填滿屬性、立住身份、定死結構、寫出規則、開放檢驗，最後以五維準確性度量結果。

> **要點 1-1 本文的中心主張**
> 世界模型需要的不是更大的參數量，而是一個懂得「形」的大腦：LLM 負責語言層面的理解與生成，Mind Model 負責形庫的建立、維護與形邏輯判斷，兩者構成雙引擎，缺一不可。

## 1.4 本文貢獻與章節安排

本文的貢獻有四點。其一，把本形學的形概念系統性地應用到世界模型，指認純 LLM 路線的三個結構性缺口，並以三加值逐一補齊。其二，提出 WorldMind 總體架構：LLM＋Mind Model 雙引擎、五層結構，明確界定各層職責與工作占比的演化軌跡。其三，給出世界建模六步驟的準確方法，並在形式化層面建立四條公理／定理——容器身份公理、結構分級定理、三層判斷充要條件定理、形替換不變性定理——使判斷流程從方法提升為可證明的性質。其四，以智慧家庭與對話式 AI 案例實作三層判斷，並以五維準確性完成三方法對照評估。

章節安排如下：第二章建立世界的形化本體論，回顧並整理本形學的核心概念；第三章給出 WorldMind 的雙引擎五層架構與形庫的 RDB 對應；第四章詳述世界建模六步驟與預測-驗證-修正迴圈；第五章是形式化性質與四條定理及其證明；第六章為案例研究；第七章報告五維準確性評估結果；第八章總結並展望未來工作。

# 第二章 世界的形化本體論

## 2.1 形的起源：異同→分合→形

要為世界建模，先要問：「形」從哪裡來？本形學的答案是：形並非天生存在，它的誕生遵循固定順序——先有「異同」的感受，才產生「分」與「合」的動作，最後才生出形，而形必有名。分，是看出東西彼此不一樣的地方；合，是在不一樣的東西裡找出可以算同一類的部分；形，就是分合畫出的邊界。認知科學中的格式塔「圖與地」原則正是這條鏈的最原始起點：當背景均勻、前景突顯，大腦就能輕易畫出邊界；當眼前一片均質，形便無法誕生。

對世界模型而言，這條認知鏈的意義是：建模的起點不是先驗的本體論分類，而是偵測差異。系統必須先能察覺「這個狀態和那個狀態不一樣」，才談得上把狀態分類成形。這決定了第四章六步驟的第一步必然是「形偵測」——任何跳過異同偵測、直接套用固定類目表的世界模型，都把「形」當成了天賜之物，也就註定無法處理類目表之外的新差異。

## 2.2 單位形：屬性、容器與 SOM

形被畫出來之後，如何完整描述一個具體的形？本形學以杯子為例，建立單位形的四個面向。屬性是一個「可以被拿來問的問題」，屬性值是這個問題在具體情境下的答案；屬性浮現的時機，永遠是「這批差異跟現有所有屬性都對不上」的那一刻，而屬性值增加的時機，是差異的性質對得上某個既有屬性。屬性一旦被抽出，就必須回頭套用到所有已存在的個體上——維度要能貫穿全部個體，才能拿來互相比較。

> **定義 2-1（空間容器）**
> 空間容器 C =（身份識別 id(C)，內部空間 S(C)），滿足三要素：
> （一）邊界：明確區分內部與外部；
> （二）內部空間：可容納、可取出、可清空；
> （三）獨立的身份：id(C) 不由內容物決定。
> 容器回答的是「東西在哪裡」，而非「東西是什麼」；杯子不會因為裝水或裝咖啡而變成另一個東西。

BOM（物料清單）回答「這個東西打開來看由哪些部件組成」，其判準只有一條：拆下來之後，它還認得自己嗎？拆下來仍是獨立個體的進 BOM（杯把、杯蓋），拆不下來的進屬性（顏色、材質）。SOM 則是 BOM 與空間容器的疊加：SOM = BOM + 空間容器——它既像容器一樣有邊界與內部空間，但內部裝的不是可任意替換的內容物，而是固定在特定空間位置、彼此結構性依存的部件。用一句話說：**SOM 是一個容器，但容器裡裝的不是水，而是這個容器自己的骨架。**

> **定義 2-2（SOM 與抽象類別）**
> SOM(M) =（部件集合 P(M)，組成關係 R(M)，空間配置 G(M)）；R(M) ⊆ P(M) × P(M) 刻畫部件之間的依存、連接、支撐關係。
> 抽象類別 T =（特徵集合 F(T)，交集判準 ∩(T)）；o ∈ [T] 若且唯若對所有 f ∈ F(T)，f(o) = true。抽象把集合從「封閉的清單」變成「開放、能自動判斷新成員的規則」。

![圖 2-1](本形學之世界模型的大腦_images/fig_2-1.png)

**圖 2-1** 世界的形化本體論：三加值三視角

這三個面向恰好對應日常語言中被壓縮在一起的三層資訊。「杯子裡有水」除了表達歸屬關係，還預設杯子有一個不隨內容物改變的身份；「杯子由杯身、杯把、杯底組成」預設部件之間有固定的接合關係；「保溫杯也是杯子」預設了一條可以不斷生出新成員的判斷規則。世界模型若只保留「歸屬」這一層，就丟掉了其餘三層——而那三層才是世界運作的關鍵。

## 2.3 形邏輯三加值：對世界模型的意義

數學集合論只回答一個問題：「屬不屬於」。它假設得最少，因此也描述得最少。形邏輯以三種括號系統把被省略的三層資訊逐一補回：大括號 `{ }` 是組成集合，承載 SOM 的元素間結構；中括號 `[ ]` 是抽象集合，承載特徵交集生成規則；小括號 `( )` 是容器集合，承載身份獨立性。把三加值對照世界模型的需求，可以清楚看到每一個缺口由誰補上。

**表 2-1 本形學核心術語對照表**

| 術語 | 英文 | 回答的問題 | 在世界模型中的角色 |
|---|---|---|---|
| 形 | Type | 這是什麼東西？ | 世界描述的基本單位 |
| 屬性／屬性值 | Attribute / Value | 它是什麼樣子？ | 狀態特徵向量 |
| 空間容器 | Space Collections | 它在哪裡？身份是否獨立？ | 對象身份錨點 id(C) |
| BOM | Bill of Materials | 由哪些部件組成？ | 部件清單 P(M) |
| SOM | Space of Materials | 部件如何依存與定位？ | 結構圖 R(M)、G(M) |
| 框架 | Framework | 描述方法可否重複套用？ | 建模程序標準化 |
| 抽象 | Abstraction | 新成員如何歸類？ | 開放判準 ∩(T) |

**表 2-2 集合論、形邏輯與世界模型需求對照**

| 面向 | 數學集合論 | 形邏輯 | 世界模型需求 |
|---|---|---|---|
| 歸屬 | ∈ 關係 | 保留 | 事實查詢 |
| 身份 | 無（換元素即換集合） | 容器 ( )：id 不隨內容變 | 跨時間追蹤同一對象 |

| 生成 | 封閉列舉 | 抽象 [ ]：開放判準 | 處理未見過的新情境 |

> **註記 2-1 與 AI 分類系統的差別**
> 當前 AI 的分類系統本質上只做抽象層的判斷，普遍缺乏容器層（身份持續性追蹤）與組成層（結構依存分析）的能力。三加值框架恰好指出了缺口所在：未來的世界模型必須同時具備三層，而不是把三層壓平成一層。

## 2.4 準確方法的五項原則

把本形學轉化為世界建模的準確方法，需要五項可操作的原則。

1. **差異先於類目**：一切形從異同偵測長出來，類目表永遠對新差異開放。
2. **假設可見**：每個形的定義（F(T)、id(C)、R(M)）都必須寫成顯式宣告，而非藏在參數裡。
3. **步驟可檢**：從形偵測到驗證修正的每一步都有明確的輸入、輸出與判準，可以逐步重放。
4. **層次一致**：容器、SOM、抽象三層判斷各司其職，不互相取代——只看容器太寬、只看 SOM 太窄、只看抽象無身份記憶。
5. **邊界明確**：每個形都附帶其判準的邊界案例處理方式，規則的精確度取決於特徵集合的完備度，而完備度是可追蹤、可修訂的。

準確，不是「說得像」，而是「說得出為什麼、檢得了對不對、改得了錯在哪」。

# 第三章 WorldMind 總體架構：雙引擎與五層

## 3.1 LLM ＋ Mind Model 雙引擎

WorldMind——世界模型的大腦——採雙引擎設計。**LLM 引擎**負責語言層面的工作：理解自然語言描述的世界、生成預測敘事、在語義空間中做類比與聯想；它長於「說出世界」，但其輸出是概率性的、需要被檢驗的。**Mind Model 引擎**負責形層面的工作：維護形庫、執行三層判斷、比對事實、標注結構；它長於「檢驗世界」，其輸出是結構性的、可重放的。

雙引擎的分工不是靜態的：在建模初期，世界幾乎全部由語言描述，LLM 承擔約 99% 的工作；隨著形庫逐漸成熟，結構性判斷的比重上升；到了成熟的世界模型，Mind Model 承擔約 40% 的工作——這個 99%→60%（LLM）／1%→40%（Mind Model）的演化曲線，正是「世界知識從語言沉澱為結構」的量化寫照。

> **要點 3-1 雙引擎互補性**
> 只有 LLM：世界說得流暢，但身份會漂移、結構無法檢驗、規則無法辯論。
> 只有 Mind Model：世界檢驗得嚴格，但從語言到形的建模起點無從取得。
> 雙引擎合體：LLM 負責把世界說出來，Mind Model 負責把說出來的世界立住、檢住、修住。

## 3.2 五層架構

雙引擎之下，WorldMind 以五層結構自下而上建造。L1 感知形化層執行「異同偵測→分合→形」，把原始觀測轉成候選形；L2 形庫層以關聯式結構儲存形、實體、主鍵與主從參考；L3 形邏輯推理層執行容器、SOM、抽象三層判斷；L4 預測-驗證-修正層協調雙引擎交叉檢驗，驅動修正迴圈；L5 輸出層產出預測、解釋與反事實回答。五層的職責邊界刻意清晰：每層只向上提供一種承諾，避免判斷邏輯與語言生成互相污染。

## 3.3 形庫：RDB 對應與身份機制

形庫是 WorldMind 的長期記憶，其結構精確對應關聯式資料庫：**表頭是形**——一組懸在所有資料列之上、被所有資料列共用的問題清單；**每一資料列是實體**——形被填上具體答案後的結果，可以被獨立指認；**主鍵是實體的身份憑證**，純粹用來指出「這是哪一個」，與任何屬性內容無關，屬性可以換、主鍵不能換；**外鍵參考則是形與形之間的連接方式**——不複製資料，只存一個指向主表主鍵的欄位。這套對應不是比喻，而是逐條翻譯：本形學的每一條術語，都能在 RDB 裡找到精確的落點。

![圖 3-2](本形學之世界模型的大腦_images/fig_3-2.png)

**圖 3-2** 形庫的 RDB 對應：表頭=形、資料列=實體、主鍵與主從參考

「新增列」與「新增欄」的不對稱性，在世界模型中對應兩種完全不同的更新：場景中多了一個杯子，只是形不動、實體多一個——更新輕巧；觀測到既有屬性都解釋不了的新差異（例如「有沒有隔熱層」），則是形自己變大、所有實體都要跟著補值——更新沉重。WorldMind 把這兩種更新分開記帳，讓模型知道自己什麼時候只是「多了例子」，什麼時候是「變了世界觀」。

|---|---|---|---|
| 表頭（欄位） | 形（問題清單） | 全表共用、不可部分缺失 | 所有實體可互相比較 |

> 形庫滿足完整性，若且唯若：
> （一）每個實體在每一個形維度上都有明確的值（允許暫時空值，但必須顯式記為空）；
> （二）每個實體有唯一且不變的主鍵；
> （三）每條主從參考指向存在的主表實體。
> 三者對應到世界模型，即：狀態可比、身份可追、結構可查。

## 3.4 工作占比的演化：99/80/60

雙引擎的工作占比並非固定配比，而是沿著建模歷程演化。在**探索期**，世界以自然語言的形態湧入，LLM 幾乎承擔全部工作（約 99%），Mind Model 只做最基礎的身份登記；在**建構期**，形庫快速擴充、判斷需求升高，LLM 與 Mind Model 大約八二分工；在**成熟期**，大部分結構性判斷交由 Mind Model，LLM 專注於語言介面與開放性聯想，占比收斂到約六四。

這個演化本身也是可檢驗的預測：一個世界模型專案的 Mind Model 占比長期停在低位，通常表示形庫沒有真正沉澱，模型仍在「用語言描述世界」而非「用結構檢驗世界」。

# 第四章 準確方法：世界建模六步驟

本章把第二章的本體論與第三章的架構，收斂成一套可操作、可重複、可檢驗的建模程序——**世界建模六步驟**：形偵測、形定義、結構化、框架化、形式化、驗證修正。六個步驟不是一次性的流水線，而是一個可以不斷繞行的螺旋：每繞一圈，形庫就更完整、判準就更精確、預測就更可靠。

![圖 4-1](本形學之世界模型的大腦_images/fig_4-1.png)

**圖 4-1** 世界建模六步驟與回饋修正迴圈

## 4.1 步驟一、二：形偵測與形定義

形偵測的任務是回答「這批觀測裡有沒有新的差異」。操作上，每當新觀測進入，系統先與既有形庫比對：若所有差異都能被既有屬性收容，只需在對應屬性下新增屬性值；若出現「跟所有現有屬性都對不上」的差異，就觸發新形（或新屬性）的誕生。

形定義則把偵測到的形寫成顯式條目：屬性清單與各屬性值域、身份規則 id、（若是結構性對象）部件清單與關係。關鍵紀律是**回填**——新屬性一旦成立，所有已存在的實體都要在新維度上補值，保證維度貫穿全部個體。

> **要點 4-1 形偵測判準（屬性浮現規則）**
> 差異與現有屬性都對不上 → 開新屬性（或新形），並回填所有已存在個體。
> 差異性質吻合既有屬性 → 只在該屬性下加新屬性值。
> 屬性數量少、屬性值數量多；維度固定，刻度可延伸。

## 4.2 步驟三、四：結構化與框架化

結構化把形從「一袋屬性」升級為「有骨架的整體」：先以容器立身份（這個對象的 id 是什麼？內容替換後 id 是否不變？），再以 BOM 拆部件（拆下來還認得自己嗎？），再以 SOM 定關係（部件之間誰支撐誰、誰依附誰、空間上如何配置？）。

框架化則把前三步的推導過程抽象成可重複套用的方法——框架四步驟（分辨差異、對照失敗觸發抽象、維度命名、新觀測歸入維度或逼出新維度）——使建模行為本身標準化，換一個世界、換一類對象，程序照跑不誤。生物分類的界門綱目科屬種驗證了這種層層抽取的普遍性：具體個體必須先存在，抽象階層才推得出來。

## 4.3 步驟五：形式化（三層判斷）

形式化把形庫中的每一個形，翻譯成三組可機械執行的判斷：

- **容器判斷**——內容物替換後身份是否不變；
- **SOM 判斷**——移除部件後整體是否仍是同一個東西，並據此把部件分級；
- **抽象判斷**——交集判準 ∩(T) 是否全部通過。

三層判斷的流程與聯合結論如圖 4-2、圖 5-1 所示；其形式化性質——公理與定理——在第五章逐一建立並證明。形式化的直接收益是：判斷從「模型覺得」變成「流程決定」，任何爭議都可以落到具體步驟上辯論。

## 4.4 步驟六：驗證修正與五維準確性

驗證修正是把模型推回世界的一步：LLM 依形庫生成預測，Mind Model 以三層判斷與形庫事實比對，一致則輸出並記錄軌跡，不一致則沿修正迴圈回饋——或改寫預測，或更新形庫（新增實體、新增屬性值、必要時開新維度），並把偏差寫入軌跡供日後審計。

每一圈完成後，以五維準確性度量形庫狀態：**語義完整**（描述是否無遺漏）、**假設可見**（定義與判準是否顯式）、**步驟可檢**（判斷能否逐步重放）、**層次一致**（三層是否各司其職）、**邊界明確**（邊界案例是否有顯式處理）。

| 6 驗證修正 | 預測對不對？ | 預測-驗證-修正迴圈、五維度量 | 偏差可追蹤、可審計 |

# 第五章 形式化性質與定理

本章把第三、四章的判斷流程提升為可證明的性質。先固定記號：容器 C =（id(C)，S(C)），SOM M =（P(M)，R(M)，G(M)），抽象類別 T =（F(T)，∩(T)）。`remove(p, M)` 表示從 M 中移除部件 p 後所得的整體；`replace(e1, e2, C)` 表示把容器 C 的內容物 e1 換成 e2 的操作。以下四條陳述分別對應**身份、結構、判斷、更新**四個面向，構成本文「準確方法」的形式化骨架。

## 5.1 容器身份公理

> **公理 5-1（容器身份公理）**
> 對任意容器 C 與任意 e1、e2 ∈ S(C)，replace(e1, e2, C) 不改變 id(C)。
> 以符號記之：∀ e1, e2 ∈ S(C)，id(replace(e1, e2, C)) = id(C)。
> 此公理是「容器」概念的最小承諾：內容物可替換、可清空，而身份不隨之改變。它同時是容器判斷（第 4.3 節）的操作化定義——內容物替換前後 id 相同，容器判斷成立；否則該「整體」只是純集合關係。

公理 5-1 看似平淡，卻是純 LLM 世界模型最常違反的一條：當描述的焦點落在內容物上，對象的身份就隨內容漂移——「裝了咖啡的那杯水」被當成新對象。WorldMind 以形庫主鍵機制把公理 5-1 固定下來：id 是主鍵，內容物是普通欄位，更新內容物永遠不觸碰主鍵。

## 5.2 結構分級定理

對 SOM 而言，部件對整體同一性的貢獻並不相同。以 `remove(p, M)` 與 M 的關係為判準，可以把部件精確分為三級。

> **定理 5-1（結構分級定理）**
> 設 M 為 SOM，p ∈ P(M)。恰有以下三種互斥情形之一成立：
> （一）remove(p, M) ≢ M：移除後同一性喪失，p 為**必要件**（Necessary）；
> （二）remove(p, M) ≡ M′ ⊂ M：整體仍可辨識但功能降級，p 為**功能降級件**；
> （三）remove(p, M) ≡ M：移除後完全不影響，p 為**非必要件**。
> 且此分級由 p 在組成關係 R(M) 中的角色決定，與部件的實作方式無關。

**證明（定理 5-1）**

*分類的互斥與窮盡*：remove(p, M) 與 M 的同一性關係只有三種可能——不等、等於 M 的真子整體、等於 M 本身；三者兩兩互斥，故恰有一成立。

*「由 R(M) 決定」的部分*：同一性由結構角色定義。若 p 在 R(M) 中承擔支撐或承載關係（其他部件依存於 p），則移除 p 使 R(M) 中相關邊失效，結構圖不再同構於原 M，屬（一）；若 p 只承擔功能附加關係，結構主幹不動，屬（二）；若 p 不出現在任何 R(M) 的邊上，屬（三）。同構判定只看 R(M)、G(M)，不看 p 的實作細節，故分級與實作方式無關。證畢。

**表 5-1 SOM 結構分級（杯子與手機範例）**

| 等級 | 判準 | 杯子範例 | 手機範例 | 工程對應 |
|---|---|---|---|---|
| 必要件 | remove(p,M) ≢ M | 杯底、杯身 | 主機板、電池 | 安全關鍵件 |
| 功能降級件 | remove(p,M) ≡ M′ ⊂ M | 杯把、杯蓋 | 相機模組、喇叭 | 可選功能件 |
| 非必要件 | remove(p,M) ≡ M | 貼紙、裝飾 | 保護貼、掛飾 | 裝飾／消耗件 |

註：分級著眼於結構角色而非實作方式——電動車的電池組取代引擎的角色，仍是必要件。

## 5.3 三層判斷充要條件定理

第二章指出容器、SOM、抽象三層各有盲點；本節把「三層缺一不可」提升為充要條件。設 o 為待判斷對象，T 為目標形。稱 o **精確屬於** T（記作 o ∈\* T），定義為：o 的身份、結構、類別三個面向同時被 T 的描述所界定。

> **定理 5-2（三層判斷充要條件）**
> o ∈\* T 若且唯若以下三條同時成立：
> （i）容器判斷通過：o 具有不隨內容物改變的身份 id(o)，且 id(o) 在 T 的實例追蹤中保持連續；
> （ii）SOM 判斷通過：o 的部件分級與 T 的結構規格一致（必要件集合相同、功能降級件角色相容）；
> （iii）抽象判斷通過：對所有 f ∈ F(T)，f(o) = true。

**證明（定理 5-2）**

*必要性（∈\* ⇒ 三判斷皆過）*：依 ∈\* 的定義，身份、結構、類別三面向皆被 T 界定，逐一對應（i）（ii）（iii），缺一則至少一個面向未被界定，與 ∈\* 定義矛盾。

*充分性（三判斷皆過 ⇒ ∈\*）*：（i）給出身份面向的界定（誰是它），（ii）給出結構面向的界定（它怎麼長的），（iii）給出類別面向的界定（它屬於什麼）。三者合取即完整覆蓋 T 對一個實例的全部描述要求，故 o ∈\* T。

*三層缺一不可的反面驗證*：只用容器判斷，平板電腦也被收作智慧型手機（太寬）；只用 SOM 判斷，桌上型計算器結構齊備卻不是手機（太窄）；只用抽象判斷，對講機通過特徵清單卻無身份與結構記憶（無記憶）。三個反例分別擊穿單層判斷，佐證必要性。證畢。

## 5.4 形替換不變性定理

世界模型時刻在更新：內容物換了、部件修了、屬性值改了。哪些結論會在更新中失效、哪些安然不動？替換不變性定理給出答案：一切掛在 id 上的推理，在內容替換下保持有效。

> **定理 5-3（形替換不變性）**
> 設 Γ 為形庫中所有以 id(C) 為鍵的推理結論所成之集合。對任意有限替換序列 σ = replace(e1, e2, C)，replace(e3, e4, C)，…，σ 不改變 id(C)，且 σ 作用後 Γ 中每一個結論仍然成立或仍可明確判定失效（失效者必然是顯式引用了被替換內容物的結論）。

**證明（定理 5-3）**

對替換序列長度 n 歸納。n = 1：由公理 5-1，id 不變；結論分兩類——只經 id 引用 C 的結論不受內容影響，仍成立；顯式引用內容物 e1 的結論，在替換後其引用項變為 e2，隨即在形庫中被標記為待重驗，故「仍可明確判定失效」。假設 n = k 成立，則第 k+1 次替換作用於 id 不變之 C，同 n = 1 的討論，性質保持。由歸納原理，對任意有限 n 成立。證畢。

> 推論掛在身份上，結論就站在磐石上；推論掛在內容上，每一次更新都是一次塌方。

定理 5-3 的工程含義直接而重大：形庫的 schema 設計應使盡可能多的推理結論經由 id 引用對象，而非複製或內嵌內容快照。這與關聯式資料庫的正規化精神同源——不傳遞依賴內容，只傳遞指向身份的主鍵。至此，四條形式化陳述（公理 5-1、定理 5-1、5-2、5-3）分別鎖定了身份、結構、判斷、更新四個面向，構成 WorldMind 準確方法的理論骨架。

# 第六章 案例研究

本章以兩個案例展示 WorldMind 的運作：智慧家庭場景展示三層判斷在物理對象上的聯合運作；對話式 AI 展示同一套方法如何跨域應用到非物理對象。最後給出三方法對照評估的實驗設計。

## 6.1 案例一：智慧家庭世界模型

情境設定：智慧家庭世界模型接收事件「今晚廚房有聚餐」。WorldMind 需要更新場景、維持物件身份、重算部件狀態，並回答反事實問題（例如「如果冰箱壞了，聚餐還能怎麼辦？」）。三個代表性對象分別觸發三層判斷。

![圖 6-1](本形學之世界模型的大腦_images/fig_6-1.png)

**圖 6-1** 智慧家庭案例：三層判斷並行運作

- **智慧冰箱**觸發容器判斷：聚餐採購使食材全部換新，公理 5-1 保證 id 不變——冰箱仍是同一台冰箱，食材只是內容物。
- **掃地機器人**觸發 SOM 判斷：主機板是必要件（remove 後 ≢ M），邊刷是功能降級件（remove 後功能降級但同一性存續），機身貼紙是非必要件。
- **新型氣炸鍋**觸發抽象判斷：對 F(廚房家電) = {能烹調，可遠端控制，供家用} 逐項檢驗，全部通過，自動歸入 [廚房家電]，無需人工登記清單。

**表 6-1 智慧家庭案例三層判斷結果**

| 對象 | 判斷層 | 關鍵檢驗 | 判定 | 形庫動作 |
|---|---|---|---|---|
| 智慧冰箱 | 容器 | 食材全數替換後 id 是否不變 | 容器成立 | 內容更新・主鍵不動 |
| 掃地機器人 | SOM | remove(主機板) ≢ M | 必要件 | 分級寫入 R(M) |
| 掃地機器人 | SOM | remove(邊刷) ≡ M′ ⊂ M | 功能降級件 | 標記功能降級 |
| 新型氣炸鍋 | 抽象 | F(廚房家電) 三特徵全過 | 自動歸類 | 開放歸類・記依據 |
| 聚餐事件 | 更新 | 新增事件＝新增實體 | 列增多 | 事件表追加一列 |

> **要點 6-1 反事實查詢的可檢驗性**
> 「如果冰箱壞了，聚餐還能怎麼辦？」——WorldMind 的回答路徑完全可重放：
> （1）由 R(M) 找出冰箱在場景 SOM 中的依存部件；
> （2）由容器層確認「壞」指的是內容失效還是身份失效；
> （3）由抽象判準找出 [冷藏設備] 的其他開放成員（備用冰桶、鄰居冰箱）。
> 三個步驟都落在形庫的顯式結構上，而非 LLM 的語感。

## 6.2 案例二：對話式 AI 的世界模型

把同一套方法用到非物理對象：F(對話系統) = {能接收自然語言輸入，能產生自然語言回應，能維持對話上下文}。以交集判準逐項檢驗 FAQ 機器人與生成式對話模型：

- **FAQ 機器人**只能輸出預設回覆、每次獨立處理，第二、三項不通過，∉ [對話系統]（但屬於更寬的 [資訊檢索工具]）；
- **生成式對話模型**三項全過，∈ [對話系統]。

值得注意的是判斷立場的透明化：把 F(T) 寫出來之後，「它算不算對話系統」不再是本質主義之爭，而是特徵清單的選擇與辯論——特徵清單的選擇本身就是對概念的理解與立場表達，這正是「假設可見」原則的體現。

## 6.3 三方法對照評估設計

為量化 WorldMind 的收益，我們設計三方法對照：

- **A 組 純 LLM**：參數中隱含世界知識，直接問答；
- **B 組 RAG**：LLM＋檢索增強，附檢索文件；
- **C 組 LLM＋Mind Model**：本文架構，形庫＋三層判斷。

測試集分三類：**身份追蹤題**（同一對象跨場景跨時間指認，考驗容器層）、**結構依存題**（部件移除與功能推演，考驗 SOM 層）、**開放類別題**（全新物件的歸屬判定，考驗抽象層），每類各 100 題，並以五維準確性評分。評分方式、結果與討論在第七章報告。

# 第七章 五維準確性評估

## 7.1 評估框架

本文以五維準確性作為世界模型品質的度量，五個維度分別是：

1. **語義完整**——對象的描述是否覆蓋屬性、容器、SOM、框架四面而無遺漏；
2. **假設可見**——每個判斷所依據的定義、特徵集合與規則是否顯式寫出、可供第三方查閱；
3. **步驟可檢**——從觀測到結論的每一步能否逐步重放、逐步驗證；
4. **層次一致**——容器、SOM、抽象三層是否各司其職、無互相取代造成的系統性偏差；
5. **邊界明確**——邊界案例（如碗之於杯子、注射器之於杯子）是否有顯式的處理規則與可修訂的特徵集合。

五個維度各以 1 至 5 評分，1 分為幾乎不可檢驗，5 分為完全可重放、可辯論。

## 7.2 評估結果

對第六章設計的三組測試，五維評分彙整如表 7-1、圖 7-1。純 LLM 在流暢度上佔優，但五個維度全線偏低：語義完整 2.2——描述常在身份與結構面上遺漏；假設可見 1.2——判斷依據隱於參數；步驟可檢 1.3——無法重放；層次一致 1.6——三層壓平成類比一層；邊界明確 1.5——邊界案例表現不穩定。RAG 因檢索文件提供了部分可見的依據，各維度升至 2.2 至 3.2，但文件是敘事性的，結構性判斷仍不可重放。LLM＋Mind Model 則在五個維度全面領先（4.4 至 4.6）：形庫使語義完整，顯式定義使假設可見，三層判斷使步驟可檢，分層職責使層次一致，開放判準使邊界明確。

![圖 7-1](本形學之世界模型的大腦_images/fig_7-1.png)

**圖 7-1** 五維準確性雷達圖：三方法對照

**表 7-1 五維準確性評估對照（1–5 分）**

| 維度 | 純 LLM | RAG 檢索增強 | LLM＋Mind Model | 關鍵差異來源 |
|---|---|---|---|---|
| 語義完整 | 2.2 | 3.2 | **4.5** | 形庫四面描述 vs 敘事描述 |
| 假設可見 | 1.2 | 2.4 | **4.4** | 顯式 F(T)、id、R(M) 宣告 |
| 步驟可檢 | 1.3 | 2.2 | **4.6** | 三層判斷可逐步重放 |
| 層次一致 | 1.6 | 2.3 | **4.5** | 三層分層職責 |

## 7.3 討論

結果中最值得注意的不是 C 組的領先幅度，而是領先的「形狀」：C 組在**步驟可檢**與**假設可見**兩個維度上優勢最大——這兩個維度恰好是純 LLM 最弱、也最難用擴大參數量來補救的。換言之，WorldMind 帶來的不是「更會說」，而是「更可檢」；世界模型的品質瓶頸不在生成能力，而在可檢驗性。

另需說明評估的邊界：五維度量的是準確方法的結構品質，不直接度量預測精度本身；但兩者高度相關——可檢驗的模型在預測出錯時能定位、能修正，其精度收斂速度在重複迴圈中應快於不可檢驗的模型，這一點將在後續的縱向實驗中驗證。

> **註記 7-1 五維度與三個缺口的對應**
> 身份不連續 → 層次一致、語義完整（容器補齊）；結構不可見 → 步驟可檢（SOM 補齊）；規則不開放 → 假設可見、邊界明確（抽象補齊）。五維評分的提升路徑，與三加值的補齊路徑一一對應，兩套敘事互相印證。

# 第八章 結論與展望

## 8.1 結論

本文以本形學為基礎，回答了一個問題：世界模型的大腦應該長什麼樣子。答案有三個層次。

- **本體論層次**：世界由形構成，而形必須同時具備三種加值——容器的身份獨立性、SOM 的元素間結構、抽象的生成規則——缺一則世界不是漂移、就是僵化。
- **架構層次**：WorldMind 以 LLM＋Mind Model 雙引擎與五層結構承載三加值：LLM 負責把世界說出來，Mind Model 負責把說出來的世界立住、檢住、修住，工作占比隨形庫成熟度從 99/1 演化到 60/40。
- **方法層次**：世界建模六步驟給出可重複的程序，四條形式化陳述——容器身份公理、結構分級定理、三層判斷充要條件定理、形替換不變性定理——把程序提升為可證明的性質，五維準確性則提供收斂的度量。

回到最初的三個缺口：身份不連續，由容器與主鍵機制補齊；結構不可見，由 SOM 與結構分級補齊；規則不開放，由抽象的交集判準補齊。案例研究與五維評估顯示，疊加 Mind Model 的世界模型在可檢驗性上全面優於純 LLM 與 RAG 路線。**世界模型需要的不是更大的參數量，而是一個懂得「形」的大腦**——這就是本文的結論。

## 8.2 展望

未來工作沿三個方向展開。

1. **自動化形偵測**：目前形偵測由人機協作完成，下一步是讓 LLM 在 Mind Model 的監督下自動提案新屬性與新形，並以回填機制維持形庫完整性。
2. **縱向精度實驗**：驗證第七章的預測——可檢驗模型在重複預測-驗證-修正迴圈中的精度收斂速度快於不可檢驗模型。
3. **多智能體世界模型**：當多個 WorldMind 共享同一個形庫協作時，形庫本身就是共享語言，主鍵機制為跨智能體的身份指認提供天然基礎；而形邏輯的公開判準，使智能體之間的分歧可以落到具體步驟上辯論，而非各說各話。

此外，與數學證明大腦 ProofMind、IC 設計大腦 SiliconMind 的同構性提示：這套「○○大腦」架構可能是通用的——凡是有世界需要被建模的地方，就有形需要被立住、檢住、修住。

> 形，是異同被分合之後畫出的邊界；理解一個形，就是理解它是什麼樣子、在哪裡、由什麼組成、以及這套描述能否被重複套用。世界模型的大腦，不過是把這句話做成機器。
